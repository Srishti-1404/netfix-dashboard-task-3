# Task 3 - Netflix Content Analytics Dashboard

## Project Overview

This project presents an interactive dashboard built using Microsoft Power BI to explore a Netflix Movies and TV Shows dataset.

## KPIs
- Total Shows
- Movies
- TV Shows

## Visualizations
- Movies vs TV Shows
- Release-year trends
- Content ratings
- Director-related analysis
- Country distribution

## Interactive Filters
- Country
- Release Year
- Show Type

## Tools Used
- Microsoft Power BI
- Power Query
- GitHub

## Files Included
- `Netflix_Content_Analytics_Task3.pbix` - Power BI dashboard
- `dashboard_screenshot.png` - Dashboard preview
- `cleaned_dataset.csv` - Cleaned dataset

## Conclusion

The dashboard summarizes Netflix content through KPIs, visualizations, and interactive filters to help users explore content types, ratings, countries, and release-year patterns.
